# Sports Viewer Mobile  

A Flutter-based mobile application for exploring and watching sports data and live streams through a public API source.  
Built to demonstrate API integration, real-time match data fetching, and modern Flutter UI concepts.  

---

## 🔍 Features  

- Real-time match listings  
- Multiple stream source options  
- Multi-language commentary support  
- Clean, minimal, and responsive interface  
- Optimized for Android and iOS
